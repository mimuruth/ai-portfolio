## Engineering Lab 13 — A study path from here

### The mental model

This book is a **map, not the territory**. Each chapter's References point at the
primary sources — the papers and official docs where the ideas are defined
precisely. Reading the source after building the project is the fastest way to turn
"I used it" into "I understand it."

### A four-week deepening plan

- **Week 1 — Retrieval & evaluation.** Re-read the RAG (2020) and BM25 papers, then
  add Precision@K labels to `prod-rag`'s golden set and compute the metric from
  Chapter 4's formulas.
- **Week 2 — Local inference.** Read the model cards for Llama 3.2, Phi-4, and
  Mistral; extend `local-slm-lab` to a 30-prompt set with a 0–5 quality rubric and
  a quantization sweep (Ch. 6, §6.8).
- **Week 3 — Fine-tuning.** Read LoRA (2021), QLoRA (2023), and DPO (2023); run
  `llm-finetuning` on a rented GPU and fill the before/after table.
- **Week 4 — Real-time & observability.** Read *Release It!* on stability patterns;
  add live provider keys to `realtime-voice` for a real latency capture, and stand
  up Langfuse for `prod-rag` traces.

### Review & exercises

- **Reflection.** For each project, write the single sentence you would put on a
  résumé — a measured outcome, not a task ("Cut RAG hallucination via enforced
  citations; faithfulness 0.87, CI-gated").
- **Synthesis.** Draw one diagram connecting all five projects (local model →
  RAG generator; fine-tuned model → voice turns; observability gating both). This
  is the story that makes a portfolio more than four separate repos.
