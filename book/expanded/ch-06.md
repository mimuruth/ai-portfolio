## Engineering Lab 6 — Benchmarking and determinism from scratch

### The mental model

Serving a local model is like a **kitchen**. **Cold start** is heating the oven
(loading weights into memory) — a one-time cost. **Warm throughput** (tokens/sec)
is how fast the chef cooks once the oven is hot. **Time-to-first-token** is how
soon the first plate leaves the pass. A 7B model has a bigger oven: slower to heat
(8.4 s cold start, measured) but its first plate can still leave quickly (126 ms
warm TTFT). The production decision — keep the oven on or not — depends on how
often orders arrive.

### Mathematical formulations

**Throughput** is decoded tokens over decode time (Ollama exposes both):

$$\text{tok/s}=\frac{\text{eval\_count}}{\text{eval\_duration (s)}}.$$

**Determinism.** Run a prompt $$n$$ times and hash each trimmed output; the
**distinct count** is $$|\{\,\operatorname{sha256}(o_1),\dots,\operatorname{sha256}(o_n)\}|$$.
At $$T=0$$ this is $$1$$ (fully reproducible); at $$T=0.7$$ it rises to $$4$$–$$5$$
of $$5$$ — the measured result.

### Bare-metal implementation — a minimal benchmark harness

Standard library only; swap the `generate` stub for a real Ollama call:

```python
import time, hashlib

def timed_generate(generate, prompt):
    t0 = time.perf_counter()
    first = None
    text = ""
    for token in generate(prompt):          # generate() yields tokens
        if first is None:
            first = time.perf_counter()     # time-to-first-token
        text += token
    t1 = time.perf_counter()
    ttft_ms = (first - t0) * 1000
    tok_per_s = len(text.split()) / (t1 - first) if t1 > first else 0.0
    return text, ttft_ms, tok_per_s

def distinct(generate, prompt, n=5):
    hashes = {hashlib.sha256("".join(generate(prompt)).strip().encode()).hexdigest()
              for _ in range(n)}
    return len(hashes)
```

> **EXAMPLE — measured comparison (Ch. 6 table).**
> ```
> llama3.2  3B : 89.6 tok/s  warm TTFT 455 ms  cold 3008 ms
> mistral   7B : 53.1 tok/s  warm TTFT 126 ms  cold 8414 ms
> distinct@T=0.0: 1/5     distinct@T=0.7: 4-5/5
> ```

> **Production note — pin the model warm.** A 7B model that idles out of memory
> pays its full cold start (**8.4 s measured**) on the next request. If latency
> matters, set `OLLAMA_KEEP_ALIVE` to keep it resident; if only throughput-per-GB
> matters, a 3B model serves more requests per unit of memory.

### Structured output: determinism is not parseability

At $$T=0$$ the model is reproducible but still wrapped JSON in prose — **0 / 5
valid** in the measured study. The fix is not a better prompt but a **validation
loop**: enforce a Pydantic schema with Instructor and retry once on invalid output.
Reliability comes from the loop, not the model's goodwill.
