## Engineering Lab 1 — Vectors, similarity, and sampling from scratch

### Mathematical formulations

**Tier 2 — the math behind "nearest in meaning."** An embedding turns a piece of
text into a vector $$\mathbf{a}=(a_1,\dots,a_n)$$. Two texts are "close in meaning"
when their vectors point in nearly the same direction. Direction is compared with
the **dot product**

$$\mathbf{a}\cdot\mathbf{b}=\sum_{i=1}^{n} a_i b_i$$

normalised by the vector lengths to give **cosine similarity**:

$$\operatorname{cos}(\mathbf{a},\mathbf{b})=\frac{\mathbf{a}\cdot\mathbf{b}}{\lVert\mathbf{a}\rVert\,\lVert\mathbf{b}\rVert},\qquad \lVert\mathbf{a}\rVert=\sqrt{\sum_i a_i^2}.$$

A value near $$1$$ means "same direction / same meaning"; near $$0$$ means
"unrelated"; near $$-1$$ means "opposite."

**Sampling.** The model outputs a score (logit) $$z_i$$ for every possible next
token. **Temperature** $$T$$ rescales the scores before turning them into a
probability distribution with the **softmax**:

$$p_i=\frac{e^{z_i/T}}{\sum_{j} e^{z_j/T}}.$$

As $$T\to 0$$ the largest logit dominates and sampling becomes deterministic
(always the top token). As $$T$$ grows, the distribution flattens and rarer tokens
get a chance — the quantitative reason Chapter 6 measures *1 distinct output / 5
runs* at $$T=0$$ versus *4–5 / 5* at $$T=0.7$$.

### Bare-metal implementation

**Tier 3 — the same math, standard library only.** No NumPy, no framework.

```python
import math

def cosine(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    na = math.sqrt(sum(x * x for x in a))
    nb = math.sqrt(sum(y * y for y in b))
    return dot / (na * nb)

def softmax(logits, temperature=1.0):
    scaled = [z / temperature for z in logits]
    m = max(scaled)                      # subtract max for numerical stability
    exps = [math.exp(z - m) for z in scaled]
    total = sum(exps)
    return [e / total for e in exps]

query = [0.9, 0.1, 0.0]
docs = {"timer trigger": [0.8, 0.2, 0.0],
        "blob storage":  [0.1, 0.2, 0.9]}
for name, v in docs.items():
    print(f"{name:15s} cos={cosine(query, v):.3f}")

print("softmax T=0.5:", [round(p, 3) for p in softmax([2.0, 1.0, 0.1], 0.5)])
print("softmax T=2.0:", [round(p, 3) for p in softmax([2.0, 1.0, 0.1], 2.0)])
```

> **EXAMPLE — output.**
> ```
> timer trigger   cos=0.986
> blob storage    cos=0.170
> softmax T=0.5: [0.84, 0.114, 0.046]
> softmax T=2.0: [0.51, 0.309, 0.181]
> ```
> Lower temperature concentrates probability on the top token; higher spreads it.

> **Production note — tokens are the unit of cost and latency.** You are billed per
> token and the context window is measured in tokens, not words. Halving the tokens
> in a prompt roughly halves its input cost *and* shortens time-to-first-token.
> Chapter 4's reranking exists partly to keep the prompt short; Chapter 5 measures
> the result at **$0.00025 / request**.
